# Release checklist

- Confirm the source-code licence and include the corresponding LICENSE file before making the repository public.
- Confirm whether the TissueAnchor source checkpoint can be published. The file is excluded from the Git tree and no release URL is asserted.
- Add the paper citation and author attribution when approved.
- Make repository visibility public only after the author review. Keep raw images, calibration manifests tracing individual subjects, checkpoints, run logs, baseline environments and data under local ignored paths.
